# 메뉴 페이지 기능 설명 추가

**날짜:** 2026-06-25  
**커밋:** `b5d5341`

---

## 요구 사항

좌측 사이드바 메뉴(대시보드 / 내역 관리 / 파일 업로드)를 클릭했을 때 메인 화면의 페이지 제목 아래에 해당 메뉴에서 사용할 수 있는 기능 설명을 추가한다.

특히 내역 관리 페이지는 파일 목록만 나열되어 있어 사용자가 파일을 클릭하면 재무제표를 조회하고 다운로드할 수 있다는 사실을 알기 어려운 상태였다.

---

## 변경 파일

| 파일 | 변경 내용 |
|------|-----------|
| `app/dashboard/page.tsx` | 대시보드 h1 아래 기능 설명 추가 |
| `app/dashboard/reports/page.tsx` | 내역 관리 h1 아래 기능 설명 추가 |

---

## 변경 상세

### 대시보드 (`app/dashboard/page.tsx`)

h1 태그와 플랜 배지를 감싸는 `<div>`로 묶고, 아래에 설명 문구를 추가했다.  
빈 상태(업로드 내역 없음)와 데이터 있는 상태 두 분기 모두 동일하게 적용했다.

```
업로드한 재무 데이터를 기반으로 손익 현황과 월별 추이를 한눈에 확인합니다.
```

### 내역 관리 (`app/dashboard/reports/page.tsx`)

파일을 클릭하면 어떤 기능을 쓸 수 있는지 명시했다.

```
업로드한 엑셀 파일 목록입니다. 파일을 클릭하면 손익계산서·재무상태표·제조원가명세서를
확인하고 PDF 인쇄 및 Excel 다운로드를 할 수 있습니다.
```

### 파일 업로드 (`app/dashboard/upload/UploadClient.tsx`)

이미 "엑셀 파일(.xlsx, .xls)을 업로드하면 손익을 자동으로 분석합니다." 설명이 존재해 변경하지 않았다.

---

## 기술 결정

- 설명 문구는 `<p className="mt-1 text-sm text-slate-500 dark:text-slate-400">` 로 통일해 기존 페이지 스타일과 일관성을 유지했다.
- 서버 컴포넌트 파일만 수정했으며 클라이언트 컴포넌트·API·타입 등 관련 없는 코드는 건드리지 않았다.
