## 변경 상세

`package.json`과 `app/`, `lib/` 구조를 확인해 실제 기능(엑셀 업로드/분석, 대시보드, 리포트 관리, 사업자 진위확인, Stripe 요금제, Supabase 인증)을 파악한 뒤 아래 세 섹션으로 구성했다.

- **서비스 개요**: 엑셀 업로드 자동 분석, 대시보드, 리포트 관리, 사업자 진위확인(국세청 API), 요금제(무료/Pro), 인증, PDF/인쇄 기능 나열
- **기술 스택**: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, Supabase, Stripe, Recharts, xlsx, react-to-print, lucide-react
- **사용 방법**: `.env.local` 환경 변수 설정 → 의존성 설치 → 개발 서버 실행 → 기타 명령어(`build`/`start`/`lint`) → 주요 사용 흐름(회원가입 → 업로드 → 대시보드 확인 → 계정 분류 수정 → 업그레이드)

## 기술 결정

- 환경 변수 값은 `.env.local`에 실제로 정의된 키 이름만 노출하고 값은 비워둔 채로 안내했다(민감 정보 노출 방지).
- 코드 구조를 직접 읽고 확인한 기능만 기술했으며, 추측성 설명은 넣지 않았다.
