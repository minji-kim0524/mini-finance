# 제조원가명세서 탭 추가 (K-IFRS)

**날짜:** 2026-06-24  
**커밋:** `ac786d2`

---

## 요구 사항

내역관리에서 파일 선택 시 표시되는 탭 메뉴(대시보드 / 손익계산서 / 재무상태표 / 계정분류)에, 재무상태표와 계정분류 사이에 **제조원가명세서** 탭을 추가한다. 제조업종 사업자를 위한 K-IFRS 준거 명세서이다.

---

## 변경 파일

| 파일 | 변경 내용 |
|------|-----------|
| `types/finance.ts` | `AccountType`에 `'mfg_cost'` 추가 |
| `lib/accountClassifier.ts` | 제조원가 계정 자동분류 키워드 추가 |
| `app/dashboard/[reportId]/ReportViewer.tsx` | 탭·뷰 컴포넌트·엑셀 내보내기 추가 |

---

## 구현 상세

### 1. `mfg_cost` 타입 신설 (`types/finance.ts`)

```typescript
export type AccountType =
  'revenue' | 'cogs' | 'mfg_cost' | 'expense' | ...
```

### 2. 자동분류 키워드 추가 (`lib/accountClassifier.ts`)

`mfg_cost` 키워드 체크를 `cogs` 체크 **이전**에 실행해 우선순위를 부여한다.

| 분류 | 키워드 예시 |
|------|------------|
| 재료비 | 원재료비, 부재료비, 재료비, 직접재료비 |
| 노무비 | 노무비, 직접노무비, 기타노무비 |
| 제조경비 | 외주가공비, 외주비, 제조경비, 공장임차료, 공장전기료 등 |

기존 `cogs` 키워드(`재료비`, `노무비`, `외주가공비` 등)와 겹치더라도 `mfg_cost`가 먼저 분류되어 올바른 명세서에 표시된다.

### 3. 제조원가명세서 뷰 (`MfgCostView`)

K-IFRS 양식에 따라 세 가지 구분으로 표시한다.

```
I.  재료비     ──── 원재료비, 부재료비 등
II. 노무비     ──── 임금, 노무비 등
III.제조경비   ──── 외주가공비, 공장임차료 등
─────────────────────────
    당기총제조원가
```

뷰 내부에서 계정명 키워드 매칭으로 재료비 / 노무비 / 제조경비를 재분류한다.

### 4. 탭 비활성화 조건

`mfg_cost` 타입 데이터가 없으면 탭이 비활성화(회색)된다. 계정분류 탭에서 수동으로 `제조원가`로 분류하면 탭이 즉시 활성화된다.

### 5. PDF 인쇄 / Excel 내보내기

기존 손익계산서·재무상태표와 동일하게:
- **PDF**: 인쇄 버튼 → A4 가로 출력
- **Excel**: `파일명_제조원가명세서.xlsx` 생성

### 6. 전기 비교

다른 보고서를 선택해 당기/전기를 나란히 비교할 수 있다.

---

## 기술 결정

- `mfg_cost` 체크를 `cogs` 앞에 두어 코드 변경 없이 우선순위를 제어한다. `cogs` 키워드는 수정하지 않아 기존 데이터에 영향 없음.
- `SubClassifyMfgCost` 함수를 모듈 수준에 정의해 뷰 컴포넌트와 Excel 내보내기 함수가 공유한다.
